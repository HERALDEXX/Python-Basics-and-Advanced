# Python Exercises, Projects & Notes — EarlyFounders Labs

A collection of Python practice exercises, projects, and personal notes from my basic and advanced Python training at EarlyFounders Labs.
It includes scripts, written notes, and various practice tasks — covering topics from beginner to advanced.

---

## 🧠 How to Explore

- Clone the repository to your local machine:

```bash
git clone https://github.com/HERALDEXX/Python-Basics-and-Advanced.git
```

- Navigate to the repo directory locally

- Run the following command to install dependencies:

```bash
pip install -r advanced_python/requirements.txt
```

- Browse any folder to view the files.
- You can open script files in any code editor (like VS Code or IDLE) and run them using Python.
- Notes and documents can be opened as plain text or markdown.

> ⚠️ This repo is not a package or installable project. It's for educational and demonstration reference only.
